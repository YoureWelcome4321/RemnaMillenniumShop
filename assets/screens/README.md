# Screen Images

Put optional bot screen images in this folder.

Supported formats:
- `.jpg`
- `.jpeg`
- `.png`
- `.webp`

Current screen keys:
- `main_menu`
- `subscribe`
- `my_subscription`
- `my_devices`
- `referral`
- `promo`
- `trial`

Examples:
- `assets/screens/main_menu.jpg`
- `assets/screens/referral.png`
- `assets/screens/my_subscription.webp`

If a file with the matching name exists, the bot will show it on that screen automatically.
